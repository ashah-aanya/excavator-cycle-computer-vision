Excavator Cycle Pipeline — Architecture

Video in → masks (GPU, once) → box features → two-pass phase search → answer.json + annotated video

Detect little, derive much

  • • Only the excavator and the truck are detected; detectors fail on object parts and dirt
  • • The bucket is found by geometry (far end of the arm), then tracked by SAM 2
  • • Slew centre, reach L, cabin and pile are all computed from the masks over time
  • • No VLM or LLM anywhere; no trained model of our own

Two-pass phase search

  • • Pass 1 asks "roughly when?": several independent cues vote on a ~1–2 s window
  • • Pass 2 asks "which frame?": one physical rule per phase picks a frame inside it
  • • Phases are searched strictly in order, each after the previous window
  • • Labels are never read; they only score the output

Nothing video-specific

  • • Times in seconds from the file's own timestamps, never frame counts
  • • Lengths as fractions of the machine's reach L, never pixels
  • • Thresholds relative to each signal's own noise and spread
  • • Horizontal cues signed toward the truck, so mirrored footage reads the same (tested on the fsm cues)
