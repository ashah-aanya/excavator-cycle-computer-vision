Calibrate globally · search locally · two passes · every function and the type it returns

Why two passes at all

  • • A trigger that fires a little early costs pass 2 a slightly longer search. A trigger that never fires loses the transition entirely — so pass 1 errs toward firing
  • • That division only works one way round: pass 2 cannot reach outside its window
  • • A refined answer from a wrong window is worse than none, because it looks precise

Invariants, fuzzed not assumed

  • • 6000 randomized walks — out-of-sequence digs, truncated holds, always-true schedules — zero violations
  • • window.lo ≤ fired_at < window.hi always
  • • Consecutive windows never overlap, so refinement cannot reorder what the walk ordered
  • • fired_at strictly increasing; every phase sequence legal
  • • advance() is atomic: both validations run before any mutation

The rule this module keeps breaking

  • • A level is not an interval. A global statistic may say what "low" MEANS; it may never say WHEN anything happened
  • • Calibrate answers what. Pass 1 answers roughly where. Pass 2 answers exactly when. Collapsing any two is how the old bracket-first design went wrong
  • • A test pins Split's field set, so growing a second bound fails the build
